# Design principles

FamilyOS is a **calm, intuitive family command center with a modern sci-fi interface**. Think precision instrument, not spaceship dashboard: atmospheric, confident, and effortless to understand.

## Experience principles

- **Clarity before cleverness:** the next useful action is obvious; labels use everyday language, not tech jargon.
- **Progressive disclosure:** show the essentials first; put advanced controls behind a clear secondary action.
- **One primary action:** each screen has a clear focal action and avoids competing calls to action.
- **Predictable navigation:** consistent placement, familiar patterns, and no hidden gestures for essential tasks.
- **Fast scanning:** strong typography, concise summaries, meaningful icons, and generous breathing room.
- **Forgiving interaction:** clear feedback, safe defaults, undo or confirmation for destructive actions, and visible loading/empty/error/offline states.

## Visual direction

- Midnight ink surfaces, cool blue-white text, luminous ion-cyan accents, and restrained ultraviolet detail.
- Layered surfaces, fine cool borders, soft depth, and subtle glow reserved for focus and important actions.
- Rounded geometry and crisp iconography; avoid generic flat white cards and default platform styling.
- Dark mode is the signature look; light mode remains a first-class, high-contrast companion.
- Use semantic colors only when they communicate status or meaning.

## Accessibility and restraint

- Minimum 48dp touch targets; WCAG AA contrast for text and controls.
- Respect reduced-motion and dynamic type; animation never blocks an action or conveys information by color alone.
- Avoid dashboard clutter, decorative gradients, tiny labels, excessive neon, and oversized cards.
- Keep screens calm: the futuristic feel comes from material, lighting, typography, and consistency—not extra controls.
