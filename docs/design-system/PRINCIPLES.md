# Design principles

FamilyOS is a **calm, warm, trustworthy family command center**.

- Clear hierarchy: what needs attention now vs background context
- Approachable surfaces, restrained sky accent (`#38BDF8`)
- Strong readability; navy foundation (`#0F172A`)
- Semantic status colors only for meaning
- Min 48dp touch targets; WCAG AA contrast
- Respect reduced-motion and dynamic type

Avoid: dashboard clutter, excessive gradients, oversized cards, decorative color that obscures meaning.
