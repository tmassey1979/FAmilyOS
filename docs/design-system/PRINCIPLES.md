# Design principles

FamilyOS is a **sci-fi modern household command center** — sharp, colorful, and easy to use.

- **Dark-first command UI**: deep space backgrounds (`#0A0E14`), navy panels, electric cyan accents
- **Clear hierarchy**: what needs attention now vs background context
- **High-energy accents**: cyan primary (`#22D3EE`), violet secondary (`#A78BFA`), punchy status colors
- **Modern controls**: 52dp touch targets, 14–18 radius, accent-edged secondary buttons
- **Semantic color only for meaning** (success / warning / danger) — never decoration that confuses status
- Strong readability and WCAG AA contrast on dark surfaces
- Respect reduced-motion and dynamic type

Avoid: flat gray utility UI, tiny hit targets, muddy borders, pure black without hierarchy, decorative noise that obscures actions.
