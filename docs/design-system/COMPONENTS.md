# Shared components (`Fo*`)

| Control | Variants |
|---------|----------|
| `FoButton` | Primary, Secondary, Danger, Ghost; Loading |
| `FoCard` | Default surface card |
| `FoBadge` | Neutral, Info, Success, Warning, Danger |
| `FoSectionTitle` | Uppercase caption |
| `FoEmptyState` | Title, subtitle, optional action |
| `FoStatusBanner` | Info, Success, Warning, Danger, Offline |
| `FoListRow` | Title, subtitle, trailing |
| `FoTextField` | Label, helper, error |
| `FoLoadingView` | Message |
| `FoErrorView` | Message + retry |

All consume semantic theme resources only. See gallery page for demos.
